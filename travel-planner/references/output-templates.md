## 12. 出发前检查

### 72小时前

- [ ] 天气与穿着更新
- [ ] 航班/列车与值机规则
- [ ] 道路、景区和预约状态
- [ ] 酒店、租车和活动订单
- [ ] 证件、保险、支付和网络
- [ ] 行李及药品

### 24小时前

- [ ] 值机、座位、行李
- [ ] 接送或停车
- [ ] 离线地图、订单截图、紧急联系人
- [ ] 设备充电和充电宝规则
- [ ] 次日衣物、早餐和出发时间

## 13. 手机每日卡片文案

每张卡只保留一屏能读完的信息。

```text
D[数字]  [日期]
[起点] → [终点]

出发  [时间]
移动  [时长/方式]
今天只抓一个重点  [核心体验]
必做  [1至3项]
预约  [项目/状态/时间]
补给  [午餐、加油/充电或饮水]
住宿  [区域/酒店]
穿着  [当天必要项]
提醒  [最大风险]
Plan B  [一句可执行备选]
```

卡片制作前逐字核对日期、时间、价格、预约和道路信息。图中不要放姓名、电话、证件、订单号、二维码、确认码和支付信息。

## 14. 行程更新说明

用户改变一个条件后，说明连锁影响。

```markdown
本次变化：[新条件]
直接影响：[日期/路线/酒店/交通/预算]
需要取消或修改：[订单]
新版推荐：[简述]
仍需确认：[待核验]
```
